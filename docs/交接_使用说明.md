# 使用说明

1. 仓库已公开，无需登录或邀请。从 Releases 下载带中文名称的完整工程 ZIP，完整解压。
2. 安装 Unreal Engine 5.8.3。右键 `四肢受损.uproject`，切换为本机 UE 5.8 后打开。
3. 默认地图 `/Game/InjuryLab/Maps/L_InjuryLab`，点击工具栏“运行”。
4. 1 闪光、2 躯干、3/4 左右臂、5/6 左右腿、7 震撼、R 重置；Tab 切换鼠标，WASD 移动，空格跳跃。也可点击界面按钮。
5. 接效果前先阅读同目录 `四肢受损系统_接口接入说明.md`，在角色的 Injury 组件绑定事件，再调用 `BroadcastCurrentState`。

ZIP 已包含 Windows 模块；如提示不兼容，请安装 VS2022 C++ 游戏开发组件重新编译。Git 克隆方式与构建目标见 README。白屏和移动减速当前只有接口，按键不会直接让画面变白或让角色变慢。
