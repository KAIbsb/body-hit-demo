# 四肢受损系统：工作与接入说明

## 当前规则

- 头部没有受损状态，不扣 80 血、不标红。只记录正常、闪光弹、震撼弹三种状态。
- 躯干受损后默认每 0.5 秒扣 1 血，最低保留 1 血；重复命中不叠加流血。治疗可停止流血、清除躯干受损并回血。普通直接伤害仍可致死。
- 左右臂、左右腿分别记录状态。手臂默认换弹耗时 ×1.5，腿部提供移速 ×0.6；双侧默认不叠加，也可切换叠加策略。
- 实际白屏、换弹动画、移动减速由前端同学接入。后端只计算数值、管理状态、发事件；已制作血条和部位状态 UI。

## 界面与调试

使用 UE 5.8.3 打开项目，默认地图 L_InjuryLab。左上为血条，右下为六块小人状态区；其余旧信息、下拉框、扣 25、恢复按钮隐藏。保留五个实验按钮：头部（震撼弹）、闪光弹、手臂中弹、躯干中弹、腿部中弹。头部按钮按新规则触发震撼弹；手臂、腿部按钮默认测试左侧。

| 按键 | 作用 |
|---|---|
| 1 | 闪光弹 |
| 2 | 躯干受损并开始流血 |
| 3 / 4 | 左臂 / 右臂受损 |
| 5 / 6 | 左腿 / 右腿受损 |
| 7 | 震撼弹 |
| R | 满血并重置全部状态 |
| Tab | 切换鼠标与视角 |

WASD 移动，空格跳跃。头部保持灰色，文字区分致盲类型；其他受损区域整块变红。UI 资产为 /Game/InjuryLab/UI/WBP_InjuryHUD，可直接在 UMG 设计器编辑。

## 接口如何使用

打开 BP_InjuryCharacter，从事件图拖出 Injury 组件引用。绑定所需事件后调用 BroadcastCurrentState，同步当前状态。

| 功能 | 调用或监听 |
|---|---|
| 伤害 | ApplyDamageToPart(部位, 伤害量)，部位用 EInjuryRegion；头部和 Unknown 会拒绝 |
| 六区状态 | GetRegionStates；头部字段为道具状态，其他五区为受损布尔值 |
| 血条 | GetHealthPercent 返回 0～1；监听 OnHealthChanged，用 Health / MaxHealth |
| 部位变色 | 监听 OnRegionInjuryChanged(Region, bInjured) |
| 换弹与减速 | 监听 OnGameplayModifiersChanged，读取耗时倍率、动画速度倍率、移速倍率 |
| 致盲 | TriggerFlashForTest / TriggerStunForTest；监听 OnBlindRequested，Type 区分两种道具 |
| 致盲结束 | 监听 OnBlindEnded；恢复、到期、死亡、组件销毁均会结束 |
| 治疗躯干 | TreatTorso(回血量)，0 表示只止血、清伤；StopBleeding 只止血 |
| 全部重置 | ResetInjuries |

换弹耗时 = 正常耗时 × GetReloadDurationMultiplier（默认 1.5）。动画播放速率 = 正常速率 × GetReloadSpeedMultiplier（默认约 0.667）。移速 = 正常移速 × GetMoveSpeedMultiplier（默认 0.6）。每次从正常基础值计算，避免重复相乘。当前角色不会自动应用减速。

白屏事件提供类型、初始透明度、持续时间、衰减曲线；前端自行显示全屏白色遮罩，每帧将透明度设为 GetBlindOpacity，到期清除。默认初始透明度 1，闪光 3 秒，震撼 1.5 秒；空曲线使用 Ease Out。自定义曲线横轴为 0～1 时间进度，纵轴从 1 衰减到 0；后端不直接绘制白屏，也未添加耳鸣。

真实爆炸可调用 EvaluateBlindExplosion(世界位置, 道具Actor, 类型)，检查视野、距离和遮挡后触发事件。

## 可调参数

在 Injury 组件详情中修改最大血量、流血间隔/单次扣血/最低血量、换弹和移速倍率、双侧叠加策略、闪光/震撼时长、初始透明度及曲线。流血最低血量至少为 1；运行中修改流血参数可调用 ConfigureBleeding。双臂叠加时耗时倍率为 1.5²=2.25，双腿叠加时移速倍率为 0.6²=0.36。

验证与重跑命令见 验证记录.md；兼容旧接口的说明见 接口详细参考.md。当前范围为本机单机实验。
