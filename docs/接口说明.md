# InjuryComponent 接口说明

项目使用 Unreal Engine 5.8.3。`UInjuryComponent` 是后端状态组件：保存血量、部位受损、流血、致盲和游戏性倍率；蓝图负责射线、伤害倍率计算、移动、换弹、白屏和 UI 表现。

蓝图资源：

- `/Game/InjuryLab/Blueprints/BP_InjuryCharacter`
- `/Game/InjuryLab/UI/WBP_InjuryHUD`

## 术语

- **受伤（Injured）**：部位耐久降到 `Part Max Health × Injured Threshold`（默认 30%）或以下；触发换弹/移速倍率和躯干流血。
- **破坏（Broken）**：部位耐久归零；HUD 进度条隐藏、部位背景整块变红，不额外死亡。
- **受损**：泛指受伤或破坏；具体判定以 `Is Region Injured` / `Is Region Broken` 为准。

## 一、FPS 命中流程

推荐蓝图流程：

```text
Line Trace By Channel
→ Break Hit Result
→ Apply External Hit
→ 得到 EInjuryRegion
→ Switch on EInjuryRegion
→ 自己计算最终伤害倍率
→ Apply Damage To Part
```

### Apply External Hit

- 输入：`Hit`，类型 `Hit Result`
- 输出：返回值，类型 `EInjuryRegion`
- 功能：读取 `Hit.BoneName`，把骨骼映射为部位枚举。
- 作用：只识别部位，不扣血，不计算倍率。
- 可能输出：`Unknown`、`Head`、`Torso`、`LeftArm`、`RightArm`、`LeftLeg`、`RightLeg`

### Resolve Region

- 输入：`Bone Name`，类型 `Name`
- 输出：`EInjuryRegion`
- 功能：直接把骨骼名映射为六区部位。
- 用途：如果已经从 `Hit Result` 中取出了 `Bone Name`，可以直接使用这个节点。

### Apply Damage To Part

- 输入：`Part`，类型 `EInjuryRegion`
- 输入：`Damage Amount`，类型 `Float`
- 输出：`Accepted`，类型 `Boolean`
- 功能：按指定部位和最终伤害更新后端状态。
- 每次命中都会扣全局血量，同时扣对应部位耐久。
- 总血归零后仍会继续扣部位耐久并触发部位破坏，方便测试；总血保持 0，不会重复触发死亡。
- 部位耐久降到 `Injured Threshold`（默认 30%）时，才标记该部位受损并触发倍率/流血。
- 手臂、腿部：部位受伤后刷新换弹/移速倍率事件。
- 躯干：部位受伤后启动流血计时。
- 头部：只扣全局血量，不建立部位耐久，也不产生头部伤口。
- `Damage Amount` 可以连接整数转换后的浮点值。

### 部位耐久

- 组件详情 `Injury|Parts`：
  - `Part Max Health`：每个部位耐久上限，默认 `30`。
  - `Injured Threshold`：受伤阈值比例，默认 `0.3`（30%）。
- `Get Part Health(Region)`：当前部位耐久；头部返回 `0`。
- `Get Part Health Percent(Region)`：`0..1`，直接连接部位进度条。
- `Get Part Max Health(Region)`：该区域耐久上限；头部返回 `0`。
- `Reset Injuries` 会把所有部位耐久回满；`Treat Torso` 会修复躯干部位耐久。
- 部位耐久归零不会额外死亡，死亡只看全局血量。

## 二、骨骼和部位查询

### Resolve Body Part

- 输入：`Bone Name`，类型 `Name`
- 输出：`EInjuryBodyPart`
- 功能：返回更细的骨骼部位，例如 `LeftThigh`、`RightHand`、`LeftCalf`。
- 常用情况：需要区分同一侧手臂或腿的具体骨骼时使用。

### Is Region Injured

- 输入：`Region`，类型 `EInjuryRegion`
- 输出：`Boolean`
- 功能：查询躯干、左右手臂、左右腿是否处于受损状态。
- 头部主要表示闪光/震撼状态，不作为普通伤口查询。

### Is Region Broken

- 输入：`Region`，类型 `EInjuryRegion`
- 输出：`Boolean`
- 功能：查询该部位耐久是否已归零（部位破坏）。
- 头部没有部位耐久，恒为 `false`；`Unknown` 同样返回 `false`。
- 与 `Is Region Injured` 的区别：受伤是耐久降到 30% 阈值，破坏是耐久归零。

### Get Region States

- 无输入。
- 输出：`FInjuryRegionStates`。
- 内容：头部状态、躯干受损、左右手臂受损、左右腿受损。
- 用途：一次性刷新部位 UI。

### Is Body Part Injured

- 输入：`Part`，类型 `EInjuryBodyPart`
- 输出：`Boolean`
- 功能：查询具体骨骼部位是否受损。

## 三、血量和状态查询

### Get Health

- 无输入。
- 输出：`Float`。
- 功能：当前血量。

### Get Max Health

- 无输入。
- 输出：`Float`。
- 功能：最大血量。

### Get Health Percent

- 无输入。
- 输出：`Float`，范围 `0` 到 `1`。
- 功能：直接连接 Progress Bar 的百分比。

### Is Bleeding

- 无输入。
- 输出：`Boolean`。
- 功能：查询当前是否流血。

### Is Dead

- 无输入。
- 输出：`Boolean`。
- 功能：查询血量是否归零。该节点属于当前已有旧逻辑，本阶段不扩展死亡规则。

### Get Blood Vision Tier

- 无输入。
- 输出：`Integer`，范围通常为 `0` 到 `4`。
- 功能：根据累计失血返回血丝/视觉状态档位。

### Get Blood Vision Opacity

- 输入：`Max Opacity`，类型 `Float`；小于 0 时使用组件 Details 的 `Blood Vision Max Opacity`（默认 `0.1`）。
- 输出：`Float`，范围 `0` 到 `Max Opacity`。
- 功能：当前血雾/血丝效果透明度；档位 0–4 按百分比映射为 0%、25%、50%、75%、100% × `Max Opacity`。
- 档位切换时按 `Blood Vision Fade Seconds`（默认 0.5 秒）做 Ease In-Out 插值；中途换档从当前值继续过渡，不会硬切。
- 配置：组件 Details -> `Injury|BloodVision` 的 `Blood Vision Max Opacity`、`Blood Vision Fade Seconds`。
- 与 `On Blood Vision Tier Changed` 的 `Strength` 区分：事件输出是 0–1 归一化值；本节点默认输出 0–0.1，传入自定义 `Max Opacity` 时输出 0–Max。


## 四、换弹和移动倍率

### Get Reload Duration Multiplier

- 无输入。
- 输出：`Float`。
- 功能：换弹总耗时倍率。
- 使用：`正常换弹时间 × 该值`。
- 默认手臂受损时约为 `1.5`。

### Get Reload Speed Multiplier

- 无输入。
- 输出：`Float`。
- 功能：换弹动画播放速度倍率。
- 使用：`正常动画速度 × 该值`。

### Get Move Speed Multiplier

- 无输入。
- 输出：`Float`。
- 功能：移动速度倍率。
- 使用：`基础 Max Walk Speed × 该值`。
- 默认腿部受损时约为 `0.6`。

### Get Recoil Multiplier

- 无输入。
- 输出：`Float`。
- 功能：兼容旧接口。目前后端返回固定值 `1`，不负责修改枪械后坐力。

## 五、致盲和头部状态

### Trigger Flash For Test

- 无输入，无返回值。
- 功能：触发测试闪光状态。

### Trigger Stun For Test

- 无输入，无返回值。
- 功能：触发测试震撼状态。

### Trigger Blindness

- 输入：`Type`，类型 `EInjuryHeadState`。
- 无返回值。
- 功能：按指定类型触发头部致盲状态。

### Evaluate Flash Explosion

- 输入：`Explosion Location`，类型 `Vector`
- 输入：`Flash Actor`，类型 `Actor Object Reference`
- 输出：`Boolean`
- 功能：根据玩家视角、距离、屏幕范围和遮挡情况判断闪光弹是否生效。

### Evaluate Blind Explosion

- 输入：`Explosion Location`，类型 `Vector`
- 输入：`Source Actor`，类型 `Actor Object Reference`
- 输入：`Type`，类型 `EInjuryHeadState`
- 输出：`Boolean`
- 功能：通用的闪光/震撼判定入口。

### Is Flashed

- 无输入。
- 输出：`Boolean`。
- 功能：查询当前是否为闪光状态。

### Is Blinded

- 无输入。
- 输出：`Boolean`。
- 功能：查询当前是否处于闪光或震撼状态。

### Get Head State

- 无输入。
- 输出：`EInjuryHeadState`。
- 结果：`Normal`、`Flashbang`、`StunGrenade`。

### Get Blind Remaining Seconds

- 无输入。
- 输出：`Float`。
- 功能：剩余致盲时间。

### Get Blind Opacity

- 无输入。
- 输出：`Float`。
- 功能：当前白屏透明度/强度，供 UI 白屏使用。

### Get Flash Remaining Seconds

- 无输入。
- 输出：`Float`。
- 功能：闪光状态剩余时间。

## 六、血量、治疗和重置

### Apply Health Damage

- 输入：`Amount`，类型 `Float`
- 无返回值。
- 功能：直接扣总血量，不指定受击部位。

### Treat Torso

- 输入：`Heal Amount`，类型 `Float`
- 无返回值。
- 功能：治疗躯干、停止躯干流血，并恢复指定血量。

### Stop Bleeding

- 无输入，无返回值。
- 功能：停止流血计时。

### Configure Bleeding

- 输入：`Interval Seconds`，类型 `Float`
- 输入：`Damage Per Tick`，类型 `Float`
- 输入：`Minimum Health`，类型 `Float`
- 无返回值。
- 功能：调整流血间隔、每次流血伤害和流血最低血量。

### Reset Injuries

- 无输入，无返回值。
- 功能：重置血量、部位受损、流血和头部状态；血雾透明度会按 `Blood Vision Fade Seconds` 淡出。

### Broadcast Current State

- 无输入，无返回值。
- 功能：把当前血量、部位、倍率、流血和头部状态重新广播一次。
- 用途：蓝图刚绑定事件或 UI 刚创建时，主动同步初始显示。

## 七、事件节点

这些节点从 `InjuryComponent` 的事件列表拖出，属于后端主动通知蓝图。

### On Health Changed

- 输出：`Health`，类型 `Float`
- 输出：`Max Health`，类型 `Float`
- 用途：刷新血条和血量文字。

### On Body Part Injury Changed

- 输出：`Part`，类型 `EInjuryBodyPart`
- 输出：`b Injured`，类型 `Boolean`
- 用途：刷新具体手、臂、腿、躯干部位显示。

### On Region Injury Changed

- 输出：`Region`，类型 `EInjuryRegion`
- 输出：`b Injured`，类型 `Boolean`
- 功能：某个部位跨过受伤阈值时广播，带部位参数；需要知道“哪个部位受伤”时用这个事件。
- 用途：刷新六区部位 UI；也可以在这里按 Region 播放受伤表现。

### On Gameplay Modifiers Changed

- 输出：`Reload Duration Multiplier`，类型 `Float`
- 输出：`Reload Speed Multiplier`，类型 `Float`
- 输出：`Move Speed Multiplier`，类型 `Float`
- 功能：聚合后的换弹/移速倍率变化事件，**不带部位参数**，不是“某个部位受伤”的事件。
- 用途：收到受伤状态变化后，更新换弹时间、动画速度和移动速度；需要知道具体部位时监听 `On Region Injury Changed`。

### On Region Broken Changed

- 输出：`Region`，类型 `EInjuryRegion`
- 输出：`b Broken`，类型 `Boolean`
- 功能：部位耐久跨过 0 时广播；`b Broken` 为当前状态。
- 触发：某部位耐久首次归零时 `true`；`Reset Injuries` 或 `Treat Torso` 修复后广播 `false`。
- 用途：只在破坏/修复瞬间刷新表现，不需要每帧查询。
- 初始化：`Broadcast Current State` 会为五个部位各广播一次当前状态；刚绑定事件或刚创建 UI 后调一次即可同步。

### On Injury Modifiers Changed

- 输出：`Recoil Multiplier`，类型 `Float`
- 输出：`Reload Duration Multiplier`，类型 `Float`
- 输出：`Move Speed Multiplier`，类型 `Float`
- 用途：旧版倍率事件，当前 FPS 优先使用 `On Gameplay Modifiers Changed`。

### On Bleeding Changed

- 输出：`b Bleeding`，类型 `Boolean`
- 用途：显示或隐藏流血效果。

### On Blind Requested

- 输出：`Type`，类型 `EInjuryHeadState`
- 输出：`Initial Opacity`，类型 `Float`
- 输出：`Duration Seconds`，类型 `Float`
- 输出：`Fade Curve`，类型 `Curve Float Object Reference`
- 用途：蓝图执行白屏、渐隐和震撼表现。

### On Blind Ended

- 输出：`Head State`，类型 `EInjuryHeadState`
- 用途：结束白屏或震撼表现。

### On Flash Requested / On Flash Ended

- `On Flash Requested` 输出：`White Strength`、`Duration Seconds`，类型均为 `Float`。
- `On Flash Ended` 无输出。
- 用途：旧版闪光事件，优先使用 `On Blind Requested`。

### On Stun Requested / On Stun Ended

- `On Stun Requested` 输出：`White Strength`、`Duration Seconds`，类型均为 `Float`。
- `On Stun Ended` 无输出。
- 用途：旧版震撼事件，优先使用 `On Blind Requested`。

### On Death

- 无输出。
- 功能：当前旧后端在血量归零时广播。
- 本阶段只保留已有接口，不增加死亡表现或死亡规则。

### On Reset

- 无输出。
- 功能：`Reset Injuries` 完成后广播。
