# 接口说明

## 项目范围

工程使用 Unreal Engine 5.8.3。后端组件负责状态、数值和事件；蓝图或前端负责白屏、移动、换弹和 UI 表现。

主要资产：

- `/Game/InjuryLab/Blueprints/BP_InjuryCharacter`
- `/Game/InjuryLab/UI/WBP_InjuryHUD`
- `/Game/InjuryLab/Maps/L_InjuryLab`

## 受击与状态

`UInjuryComponent::ApplyDamageToPart(EInjuryRegion Part, float DamageAmount)` 是统一受击入口。可用区域：`Head`、`Torso`、`LeftArm`、`RightArm`、`LeftLeg`、`RightLeg`。头部不建立伤口，只通过闪光弹或震撼弹入口改变状态。

`GetRegionStates()` 返回头部道具状态和躯干、左右臂、左右腿的受损状态。`OnRegionInjuryChanged(Region, bInjured)` 通知躯干和四肢状态变化；`OnHeadConditionChanged` 通知头部状态变化。

## 李毕恺毅负责的倍率

监听 `OnGameplayModifiersChanged(ReloadDurationMultiplier, ReloadSpeedMultiplier, MoveSpeedMultiplier)`：

- 换弹总耗时 = 正常耗时 × `GetReloadDurationMultiplier()`，默认 `1.5`。
- 动画播放速率 = 正常速率 × `GetReloadSpeedMultiplier()`，默认约 `0.667`。
- 移动速度 = 正常速度 × `GetMoveSpeedMultiplier()`，默认 `0.6`。

每次都从正常基础值计算，避免重复相乘。双侧默认统一倍率；组件可切换为双侧叠加策略。

当前 `AInjuryLabCharacter` 的 `MaxWalkSpeed` 默认是 `600`，组件不会自行修改角色移动速度，需要角色蓝图或角色类监听事件后设置为基础值乘倍率。

## 血条和部位 UI

- `GetHealthPercent()` 返回 0 到 1 的血量百分比。
- `OnHealthChanged(Health, MaxHealth)` 通知血量变化。
- `GetRegionStates()` 或 `OnRegionInjuryChanged` 用于刷新右下角部位状态。
- 蓝图绑定事件后调用一次 `BroadcastCurrentState()`，同步当前状态。

## 调试按键

`1` 闪光，`2` 躯干，`3/4` 左右臂，`5/6` 左右腿，`7` 震撼，`R` 重置，`Tab` 切换鼠标和视角。

## 其他接口

`TriggerFlashForTest`、`TriggerStunForTest` 触发测试致盲；监听 `OnBlindRequested` 和 `OnBlindEnded` 接入白屏。`ResetInjuries` 重置所有受损状态。
