# 当前进度

更新时间：2026-10-19

## 项目状态

- `FPSPractice` 已完成基础玩法：移动、动画、瞄准、射击、开火音效、枪口火焰、抛壳、后坐力、换弹和 HUD。
- `InjuryComponent` 已接入 `BP_FPSPlayer`：射击射线命中后解析部位、计算最终伤害，再更新总血和部位状态。
- 新增部位耐久：默认 `PartMaxHealth = 30`，`InjuredThreshold = 0.3`；躯干和四肢共用，头部没有部位耐久。
- HUD 已迁移到 `WBP_InjuryHUD`：5 条部位进度条，正常 `90EDCDFF`、受伤红色；耐久归零时隐藏进度条并把部位背景整块变红。
- `UI_MainUI` 已移除，弹药、准心等内容并入 Injury HUD。
- FPS 输入已改为 Enhanced Input：`IA_Reset`（F 重置）、`IA_Flash`（Z 闪光）、`IA_Stun`（X 震撼）、`IA_Reload`（R 换弹）。
- 旧的手动实验按钮、1–7/R 调试键、smoke test 和对应后端入口已移除。

## 当前演示规则

- 当前射击演示按“命中后对玩家自身 Injury 结算”处理。
- 伤害倍率：头部 5、躯干 1、手臂/腿 0.7；`BaseDamage` 默认 10。
- 四肢/躯干约 3 枪进入受伤；头部只扣总血，不建立部位耐久。
- 部位耐久归零不会额外死亡，死亡只看总血量。
