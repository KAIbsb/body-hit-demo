## 本次已完成

后端新增 FPS 外部命中部位识别：

```text
ApplyExternalHit(Hit: Hit Result) -> EInjuryRegion
```

节点只读取 `Hit.BoneName` 并返回：`Unknown`、`Head`、`Torso`、`LeftArm`、`RightArm`、`LeftLeg`、`RightLeg`。它不扣血、不计算伤害倍率。

蓝图后续按枚举计算最终伤害，再调用：

```text
ApplyDamageToPart(Part: EInjuryRegion, DamageAmount: Float) -> Boolean
```

`ApplyDamageToPart` 当前支持 `Head` 扣血；头部不会建立普通头部伤口。手臂、腿部、躯干仍会更新受损状态和已有事件。相关测试和接口文档已更新。

后端编译命令已成功：`InjuryLabEditor / Win64 / Development`。

## 打开和运行

- 默认地图：`/Game/InjuryLab/Maps/L_InjuryLab`
- `1`：闪光弹
- `2`：躯干受损并开始流血
- `3 / 4`：左臂 / 右臂受损
- `5 / 6`：左腿 / 右腿受损
- `7`：震撼弹
- `R`：重置
- `Tab`：切换鼠标与视角
- `WASD`：移动；`空格`：跳跃

## 协作提醒

- UE `.uasset` 是二进制文件，同一资产不要多人同时编辑。
- 不要对其他协作者正在使用的分支 force push 或 rebase 改写历史。
- 第三协作者可能从旧提交处分支；需要同步时优先让其合并最新提交，或等本分支合并后从最新 `main` 创建新分支。
