## 本次已完成

- FPS 射击射线命中后调用 `ApplyExternalHit` 解析部位，再按部位倍率计算最终伤害并调用 `ApplyDamageToPart`。
- 新增部位耐久：`PartMaxHealth` 默认 30，`InjuredThreshold` 默认 0.3；躯干和四肢共用，头部没有部位耐久。
- 部位耐久跌到阈值后才会进入受伤状态，触发换弹/移速倍率和躯干流血。
- HUD 使用 5 条部位进度条：正常 `90EDCDFF`，受伤红色；耐久归零时隐藏进度条，部位背景整块变红。
- 头部没有部位条，状态由 `HeadStateText` 区分正常/闪光/震撼。
- 新增 `IA_Reset`、`IA_Flash`、`IA_Stun`，在 `BP_FPSPlayer` 中接入 `ResetInjuries`、`TriggerFlashForTest`、`TriggerStunForTest`。
- 移除了手动实验按钮、1–7/R 调试键、smoke test 和相关旧入口。
- `UI_MainUI` 已移除，弹药、准心等内容并入 Injury HUD。
- 左臂受伤时换弹变慢，换弹蒙太奇和 Foley 音效共用 `ReloadRate`。
- 任意腿受伤时移速下降，任意腿破坏后禁止冲刺。
- 腹部受损时降低鼠标灵敏度；右手受损时提高后坐力。
- 重置时恢复弹药：`TotalAmmo = 150`、`CurrentAmmo = MagSize`。
- HUD 新增 `VisualEffectsLayer_0/1/2` 三层视觉效果层；第三层当前接溅血透明度。
- 新增 `GetBloodVisionOpacity`：Tier 0–4 映射到 0–0.3，默认 0.5 秒插值。

## 打开和运行

1. 使用 UE 5.8.3 打开 `四肢受损.uproject`。
2. 默认进入 `Lvl_FirstPerson`；GameMode 使用 `BP_FPSGameMode`。
3. 点击运行，射击/按键触发受伤和 HUD 更新。
4. C++ 改动需要关闭编辑器后重新构建 `InjuryLabEditor / Win64 / Development`。

## 伤害和部位规则

- `BaseDamage` 默认 10；头部倍率 5，躯干 1，手臂/腿 0.7。
- 当前演示按“命中后对玩家自身 Injury 结算”处理。
- 四肢/躯干约 3 枪进入受伤；受伤后部位条变红。
- 躯干受伤后开始非致死流血，默认每 0.5 秒扣 1，最低保留 1 HP。
- 头部只扣总血，没有部位耐久，也不会建立头部伤口。
- 部位耐久归零不会额外死亡；死亡只看总血量。
- 部位耐久归零后禁止冲刺；总血归零后仍可继续扣部位耐久，便于测试。
- 溅血从 30% 血量以下开始，按 30/20/10/5% 分四档，0–5% 保持最高档；最大 0.3，切换时 0.5 秒 Ease In-Out 插值。
- 重置会回满总血、部位耐久并结束闪光/震撼。
