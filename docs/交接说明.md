# 交接说明

## 打开和运行

- 引擎：Unreal Engine 5.8.3，Windows 64 位。
- 打开 `四肢受损.uproject`，默认地图为 `/Game/InjuryLab/Maps/L_InjuryLab`。
- 点击运行后使用键盘或界面实验按钮。

## 按键

- `1`：闪光弹
- `2`：躯干受损并开始流血
- `3 / 4`：左臂 / 右臂受损
- `5 / 6`：左腿 / 右腿受损
- `7`：震撼弹
- `R`：恢复满血并重置状态
- `Tab`：切换鼠标与视角
- `WASD`：移动；`空格`：跳跃

## 当前已完成

后端已提供六区状态、非致死流血、治疗、闪光/震撼事件、换弹倍率、动画速度倍率、移速倍率和调试输入。HUD 已有左上血条、右下部位状态区和实验按钮。

## 当前限制

尚未接入实际白屏、耳鸣、换弹动画和腿伤移动减速。没有完整枪械、敌人、弹道、多人联网或独立打包版本。

## 资产协作

蓝图、地图、动画等 `.uasset` / `.umap` 是二进制资产。编辑前先在群里确认负责人，避免多人同时修改同一资产。代码和文档修改后正常提交 Git；UE 资产使用 Git LFS。

## 验证

已有后端规则、接口和基础 HUD 验证记录。后续完成前端接入后，应在 UE 5.8.3 中按按键重复验证，并把结果补充到 `docs/当前进度.md`。
