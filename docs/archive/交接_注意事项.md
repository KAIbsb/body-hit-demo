# 注意事项

- 引擎要求：Unreal Engine 5.8.3，Windows 64 位。Git 克隆包含 C++ 源码，需要 VS2022 C++ 游戏开发组件；ZIP 附带本版本的已编译 DLL。
- 已知限制：未做多人联网、完整枪械或独立游戏打包。白屏/耳鸣、换弹动画、移动减速由前端接入；不要把接口数据误认为效果已经播放。
- 保留后端与表现解耦；不要在 InjuryComponent 中直接操作 UI 或镜头。腿伤事件不得由本组件自行写角色实际移动速度。
- 接倍率时从正常基础值计算，避免重复相乘。换弹耗时倍率与动画速度倍率互为倒数。
- 蓝图和地图是二进制资产，编辑同一文件前与同事确认负责人并使用 LFS 锁定；不要同时修改同一蓝图后指望自动合并。
- 不要删除 `Source/InjuryLab`、`Source/InjuryLabEditor`、实验 Blueprint/UI/Maps 或更改接口名称后遗漏接入方。
- `Scripts/Build-InjuryLab.ps1` 等本机验证脚本含原开发机路径，换电脑须调整路径；普通打开与运行无需执行这些脚本。
- 发布 ZIP 包含真实资产。不要用只有 Git LFS 指针的自动源码 ZIP 直接运行。
