# 接口详细参考（新规范）

以同目录《四肢受损系统_接口接入说明.md》为主。此前的头部 80 伤害和每秒 5 血流血规则已被新规范替换。

## 状态与入口

- EInjuryRegion：Unknown、Head、Torso、LeftArm、RightArm、LeftLeg、RightLeg。
- FInjuryRegionStates：Head 为 EInjuryHeadState（Normal、Flashbang、StunGrenade）；躯干和左右臂/腿为五个受损布尔值。头部没有受损字段。
- ApplyDamageToPart(Region, DamageAmount)：统一入口。伤害量为有限非负数；头部、未知部位、已死亡角色会拒绝。有效部位立即扣指定血量，躯干同时启动流血。调试按钮/按键使用 0 伤害，只改变受损状态。
- GetHealth / GetMaxHealth / GetHealthPercent：当前血量、最大血量、0～1 百分比。
- OnRegionInjuryChanged：只发布躯干与四肢的受损变化。OnHeadConditionChanged 单独发布头部道具状态。
- OnGameplayModifiersChanged：ReloadDurationMultiplier、ReloadSpeedMultiplier、MoveSpeedMultiplier。耗时与动画速度互为倒数。

默认双侧 Unified，不累乘。StackBothSides 按左右两侧各算一次；同侧上臂、手等多处受损不再额外叠加。

## 流血

BleedIntervalSeconds=0.5、BleedDamagePerTick=1、BleedMinimumHealth=1。首次扣血发生在一个间隔后，重复受损不推迟计时。最低血量参数会限制在 1～最大血量之间；低于下限时流血不再扣血，也不会自动回血。下限只约束流血，直接伤害仍能致死。

ConfigureBleeding 在运行中修改三项参数，改变间隔时更新计时器。StopBleeding 仅停止计时器；TreatTorso(HealAmount) 同时清除躯干受损、停止流血并回血，上限为最大血量。死亡不能通过治疗入口复活；ResetInjuries 用于重置实验。

## 致盲

TriggerBlindness(Type) / TriggerFlashForTest / TriggerStunForTest：不扣血、不建立头部伤口。Type=Normal 无效。

OnBlindRequested(Type, InitialOpacity, DurationSeconds, FadeCurve) 发出开始请求；OnBlindEnded(Type) 发出对应类型结束事件。GetHeadState / IsBlinded / GetBlindRemainingSeconds / GetBlindOpacity 可随时查询。

默认 BlindInitialOpacity=1，FlashDurationSeconds=3，StunDurationSeconds=1.5，BlindEaseOutExponent=2。未指定 BlindFadeCurve 时，剩余透明度为 InitialOpacity × (1-progress)^2，相当于从不透明向透明 Ease Out。自定义 UCurveFloat 的横轴为归一化时间，纵轴为剩余透明度比例。前端直接读取 GetBlindOpacity 可避免重复实现衰减与迟绑定时间偏差。

同类型重复触发不会缩短已有剩余时间；不同类型以后一次为准，先结束旧类型，再请求新类型。到期、恢复、死亡、销毁组件均发结束事件。EvaluateBlindExplosion 对两种道具使用摄像机屏幕范围、FlashMaxDistance（默认 2000 cm）和 Visibility 遮挡判定；SourceActor 用于忽略道具自身。

BroadcastCurrentState 同步血量、五区状态、倍率、流血与头部状态；若仍在致盲，会提供当前透明度与剩余时长。前端绑定后调用一次即可。

## 旧接口兼容

EInjuryBodyPart 保留骨骼细分映射，供旧调用者使用。Head 名称只用于识别骨骼，ApplyBulletHit(Head) 会拒绝，IsBodyPartInjured(Head) 永远为 false，也不会发布头部伤口事件。

ApplyBulletHit / ApplyBulletHitFromHit 仍可测试手臂、腿及躯干；手臂和腿默认即时伤害为 0。ResolveRegion 可把手、前臂、大腿、小腿、脚映射到对应侧整区；BoneOverrides 支持自定义骨骼。

UE Apply Point Damage 会读取真实 BoneName，扣传入伤害一次并标记部位。使用此自动入口时不要再次调用 ApplyDamageToPart，避免重复计算。胶囊/未知骨骼和头部会被拒绝。

OnInjuryModifiersChanged 仍可兼容旧接线，后坐力倍率固定为 1；新规格不计算后坐力惩罚。OnFlashRequested / OnFlashEnded 仅对应闪光弹，OnStunRequested / OnStunEnded 对应震撼弹。建议新接入统一使用 OnBlindRequested / OnBlindEnded。

血丝分档的旧查询和事件保留兼容，不在当前 HUD 展示，也不绘制效果。实验角色没有自动减速、换弹或白屏接线。
